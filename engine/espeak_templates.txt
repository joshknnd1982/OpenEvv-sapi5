# The openevv module that speaks each eSpeak NG language, where it is chosen
# by hand. One line a pack: its tag and the template. Everything not named
# here takes the template whose phones come closest to the sounds the language
# uses, counted over eSpeak NG's own test sentences (make_espeak_packs.py
# --report shows the scores).
#
# A template is an accent: every word of the language is said with that
# module's sounds, rhythm and melody. So the first question is not which
# module has the most of the language's sounds but whose accent the language
# is least wrong in -- a relative's, or a neighbour's. Irish is spoken with
# the British English module, not the Italian one; Brazilian Portuguese with
# the Latin American Spanish one. Only where openevv has no relative or
# neighbour of a language does the count of sounds decide.
